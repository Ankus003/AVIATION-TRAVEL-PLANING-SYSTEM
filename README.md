# ✈️ Aviation Travel Planning System

An AI-powered travel planner that generates personalized travel itineraries based on user preferences. The application recommends destinations, hotels, flight booking sources, places to visit, and the best time to travel, with the ability to regenerate plans through an interactive and responsive UI.


## Youtube DEMO LINK
https://youtu.be/q9-H7qcF3O0

## Features

- ✈️ AI-powered travel itinerary generation
- 🔄 Regenerate travel plans instantly
- 🏨 Hotel recommendations
- 🎫 Flight booking source suggestions
- 📍 Tourist attraction recommendations
- 🌤️ Best time to visit destinations
- 📱 Responsive Streamlit interface

## Tech Stack

- Python
- Streamlit
- LangChain
- LangGraph
- Groq API
- Tavily Search API
- PostgreSQL (PostgresSaver)
- Python Dotenv
